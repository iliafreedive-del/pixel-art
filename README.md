# Пепел Бездны

Оригинальный пиксельный экшен-RPG в браузере. Бег по подземельям, орды монстров, задачи на локациях (обелиски, вожаки, ритуалы, боссы), дерево умений с ветками и дары алтарей.

**Играть:** https://iliafreedive-del.github.io/pixel-art/

Вся графика рисуется кодом при загрузке: спрайты героев и монстров, плиты пола, стены, предметы, иконки, свет. Внешних картинок и звуков нет, звук синтезируется WebAudio.

## Управление

| ПК | Телефон |
|---|---|
| `WASD` — бег, мышь — прицел | левый палец — джойстик |
| `ЛКМ` — основная атака | касание справа — удар в точку |
| `ПКМ` / `Q` — умение 2, `Пробел` — умение 3, `E` — умение 4 | кнопки умений справа внизу |
| `T` — дерево умений, `Esc` — пауза, `M` — звук, `F` — счётчик FPS | |

## Как устроено

- Без сборки: `index.html` + ES-модули в `js/`. Локально: `python3 -m http.server` и открыть `http://localhost:8000`.
- `js/pixel.js` — пиксельный художник (затенение с дизерингом, палитры со сдвигом оттенка, контур, подсветка края).
- `js/art/` — спрайты (`sprites.js`), окружение (`env.js`), иконки (`icons.js`).
- `js/world.js` — генерация локаций, запекание пола, поле путей для орд.
- `js/game.js` — бой, ИИ, боссы, задачи, добыча, сохранение (localStorage).
- `js/skills.js` — 12 умений, у каждого 3 ветки × 3 ступени.
- `js/render.js` — изометрия, сортировка по глубине, карта света, свечение.
- `js/ui.js` — выбор героя, путь, HUD, дерево умений, дары.
- `?fps` в адресе показывает счётчик кадров.
